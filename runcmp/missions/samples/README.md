# Complete, real mission files

Every focus has a full sample here, taken verbatim from production batteries — not sketches:

- `union.md` — the all-encompassing report over a whole campaign
- `harness.md` — which system to run, per task and overall
- `treatment.md` — before/after one deliberate change
- `variability.md` — run-to-run spread over replication groups
- `notes.txt` — operator-declared facts passed with --note @notes.txt

Regenerate for YOUR corpus with `python -m runcmp mission --corpus ... --focus <name>`; never splice an old mission's corpus description forward.
